# Сервер SFU Market

Минимальный ASP.NET Core API на .NET 10. Единственный маршрут GET /health возвращает HTTP 200 и JSON с полями status, service, version. Это проверка доступности процесса, не готовности базы данных.

Запуск и автоматическая проверка описаны в корневом README.

## Решение по замечанию о базе данных

По обсуждению 17.10.2026 проверка PostgreSQL нужна после его подключения. Пока /health возвращает ok, если сервер принимает запрос; это не гарантия готовности функций, использующих данные. На следующем этапе следует добавить отдельную проверку готовности: при недоступности БД она должна возвращать ошибку, а не постоянный положительный ответ.
