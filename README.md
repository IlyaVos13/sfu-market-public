# SFU Market

Учебная система объявлений для университетского сообщества. Это отдельная очищенная копия технического выпуска 0.1.0.

## Текущий этап

Реализован только сервер ASP.NET Core с GET /health и автоматической проверкой. База данных, интерфейс и функции объявлений будут добавляться позднее. В docs находятся требования, модели процессов, архитектура и модель данных.

## Запуск

Нужны .NET SDK 10 и Python 3. Из корня проекта:

```sh
dotnet build backend/SfuMarket.Api -c Release
python3 tests/check_health.py
dotnet run --project backend/SfuMarket.Api --urls http://127.0.0.1:5080
```

На Windows вместо python3 используется py -3. Откройте http://127.0.0.1:5080/health. Ожидаются HTTP 200 и JSON с полями status=ok, service=sfu-market, version=0.1.0. Для неизвестного адреса возвращается 404. Остановка сервера: Ctrl+C.

/health подтверждает доступность процесса, но не проверяет базу данных.
