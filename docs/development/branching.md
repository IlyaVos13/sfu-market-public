# Правила разработки

Используется GitHub Flow: main и короткие ветки задач. Коммит содержит тип изменения и номер задачи. Изменения в main принимаются через Pull Request после содержательного ревью другим участником и успешной проверки API.

Для публичной копии планируется обязательное одобрение, успешный health-check, закрытие обсуждений и запрет обхода правила администратором. Состояние защиты подтверждается отдельно после публикации.

Начальный коммит - экспорт готового технического этапа, а не новая история индивидуальной работы. Исходные запросы и обсуждения находятся в закрытом репозитории.
