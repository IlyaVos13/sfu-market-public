# Архитектура SFU Market

## C4 Level 1 - контекст
Контекстная диаграмма (см. редактируемую схему в этой папке): продавец размещает предложения, покупатель ищет вещи, администратор модерирует. Внешние системы - Telegram/VK (каналы связи) и сервис карт. Интеграция ограничена пользовательскими переходами по ссылкам, а не вызовами их API. Университетская SSO, платежи и доставка не входят в объем проекта.

## C4 Level 2 - контейнеры
Диаграмма контейнеров (см. редактируемую схему в этой папке): браузерное Web UI React, один Backend API ASP.NET Core, PostgreSQL и хранилище фотографий. UI передает JSON и multipart/form-data в API; API использует EF Core/Npgsql для SQL и файловый ввод-вывод для фото. Браузер не подключается к БД. Закрытые фото сервер выдает только после проверки доступа. Слово «контейнер» здесь не означает Docker.

Данные владельца и роли проверяются на сервере. Логические модули сервера: учетные записи, объявления, модерация, уведомления. Они не являются отдельными развертываемыми приложениями.

Редактируемые схемы находятся в файлах .puml этой папки. Главный выбор зафиксирован в [ADR-001](../adr/001_architecture_style.md).
