## [0.1.0] - 2026-10-17

### Added
- Минимальный ASP.NET Core API с GET /health.
- Автоматическая проверка HTTP 200, JSON и HTTP 404.
- GitHub Actions, инструкция запуска и текстовые материалы проектирования.

Это очищенный экспорт первого учебного релиза. История ревью и разрешения конфликта остается в исходном закрытом репозитории. База данных и пользовательский интерфейс в выпуск не входят.
